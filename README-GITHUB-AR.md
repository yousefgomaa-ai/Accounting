# ميزان — التشغيل والنشر المستقل

تطبيق React/Vinext يعمل على Cloudflare Workers بقاعدة بيانات Cloudflare D1. المشروع مستقل تمامًا: لا يعتمد على ChatGPT ولا على أي منصة أخرى. تسجيل الدخول بالبريد الإلكتروني وكلمة المرور، والجلسات محفوظة في قاعدة البيانات.

## التشغيل على جهازك

يلزم Node.js 22.13 أو أحدث (يُفضّل 24 LTS).

```bash
npm ci
npm run build
npm run db:migrate:local
npm run preview
```

افتح http://localhost:8787 واختر «تسجيل الدخول» ثم «حساب جديد». البيانات المحلية محفوظة في مجلد `.wrangler` ولا تُرفع إلى GitHub.

للتطوير مع التحديث التلقائي استخدم `npm run dev` (على http://localhost:5173) بعد تطبيق الترحيلات.

## النشر على الإنترنت (Cloudflare — الخطة المجانية تكفي)

1. أنشئ حسابًا مجانيًا على https://dash.cloudflare.com.
2. سجّل الدخول من الطرفية:
   ```bash
   npx wrangler login
   ```
3. أنشئ قاعدة البيانات:
   ```bash
   npx wrangler d1 create mizan
   ```
   انسخ قيمة `database_id` التي تظهر وضعها مكان الأصفار في ملف `wrangler.jsonc`.
4. أنشئ الجداول في قاعدة الإنتاج:
   ```bash
   npm run db:migrate:remote
   ```
5. انشر الموقع:
   ```bash
   npm run deploy
   ```
   يظهر في النهاية رابط الموقع، مثل `https://mizan.<اسمك>.workers.dev`. يمكن ربط نطاق خاص من لوحة Cloudflare.

عند أي تعديل لاحق: `npm run deploy`. وعند إضافة ترحيل جديد في `drizzle/`: `npm run db:migrate:remote` قبل النشر. لا تعدّل ترحيلًا سبق تطبيقه؛ أضف ترحيلًا جديدًا.

GitHub Pages لا يصلح لهذا المشروع لأنه استضافة ثابتة لا تشغّل الخادم ولا قاعدة البيانات.

## الأمان

- كلمات المرور مخزّنة بتجزئة PBKDF2-SHA256 مع ملح عشوائي، ولا تُحفظ نصًا.
- الجلسة في كوكي HttpOnly وSecure وSameSite=Lax لمدة 30 يومًا، ويُخزَّن في القاعدة بصمتها فقط.
- بعد 10 محاولات دخول خاطئة لنفس البريد يُوقف الدخول 15 دقيقة.
- التسجيل مفتوح لأي زائر، وكل مستخدم يرى شركاته فقط.
- لا يوجد بعد استرجاع لكلمة المرور بالبريد.

لا ترفع `.env` أو `.dev.vars` أو مجلد `.wrangler` إلى GitHub.

## نقل البيانات من النسخة القديمة

حسابات النسخة القديمة كانت مرتبطة بدخول ChatGPT، وبياناتها في قاعدة تديرها تلك المنصة، ولا تنتقل تلقائيًا. قبل إلغاء الموقع القديم، افتح كل شركة واستخدم «تصدير نسخة كاملة» لحفظ ملف JSON بالبيانات.
